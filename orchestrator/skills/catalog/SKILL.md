# Каталог плагинов

Показывай пользователю доступные плагины, их скиллы и команды, помогай выбрать подходящий под задачу.

## Порядок работы

1. Загрузи полный список из `references/plugin-catalog.md`.
2. Сопоставь запрос пользователя с подходящим плагином и скиллом по таблице "Что для чего".
3. Представь результат понятно: плагин → зачем нужен → ключевые скиллы (и команды, если есть).
4. Если пользователь не знает, что выбрать, задай 2–3 уточняющих вопроса (роль, задача, используемые инструменты) и дай конкретную рекомендацию: какой плагин установить и какой скилл запустить первым.

## Правила

- Список плагинов и скиллов бери только из каталога, не выдумывай.
- Помечай скиллы, которые срабатывают автоматически (по описанию задачи), и отдельно упоминай явные команды.
- Если задача межфункциональная, отметь это и предложи перейти к сквозному процессу (скилл `cross-functional-workflow`).
- Отвечай на русском языке.
