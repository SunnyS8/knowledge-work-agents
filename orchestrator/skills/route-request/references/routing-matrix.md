# Матрица маршрутизации

Сопоставляет типовые запросы с плагином и скиллом. Если запрос пользователя покрывает несколько строк — это кандидат на сквозной процесс (`cross-functional-workflow`).

## Продажи и рост (sales)

| Запрос | Скилл |
|---|---|
| Подготовь меня к звонку / встрече с [компания] | call-prep |
| Исследуй компанию / контакт перед первым контактом | account-research |
| Напиши аутрич / email / LinkedIn-сообщение | draft-outreach |
| Прогноз по воронке, квоте, сценарии | forecast |
| Разбери воронку: здоровье, риски, приоритеты | pipeline-review |
| Обработай заметки / транскрипт после звонка | call-summary |
| Собери конкурентную разведку / battlecards | competitive-intelligence |
| Сделай ассет для конкретного проспекта (лендинг, one-pager, дек) | create-an-asset |
| Ежедневный бриф продавца | daily-briefing |

## Особые случаи

- Запрос затрагивает несколько доменов → `cross-functional-workflow`.
- Нужен только просмотр/подпись PDF → `pdf-viewer` → view-pdf (или команды annotate/sign/fill-form/open).
- Доклинические исследования, геномика, литература → `bio-research`.
