# Orchestrator Plugin

Оркестратор плагинов [knowledge-work-plugins](https://github.com/SunnyS8/knowledge-work-plugins): направляет задачу пользователя к нужному скиллу и ведёт сквозные межфункциональные процессы целиком. Работает в [Claude Cowork](https://claude.com/product/cowork) и Claude Code, поверх плагинов маркетплейса.

## Зачем нужен

Когда установлено много плагинов, непонятно, какой скилл сработает на задачу. Оркестратор:

- **Понимает задачу** и определяет затронутые домены.
- **Маршрутизирует** её к правильному скиллу (sales, marketing, finance, legal, data, HR, engineering, design, operations, customer-support, product-management, small-business и др.).
- **Координирует сквозные процессы** — запуск продукта, найм, закрытие месяца, онбординг клиента, внедрение изменений — секвенирует скиллы разных плагинов и передаёт артефакты между шагами.

## Структура

```
orchestrator/
├── .claude-plugin/
│   └── plugin.json              # Манифест
├── README.md
└── skills/
    ├── start/                   # Входная точка: определяет сценарий
    │   └── SKILL.md
    ├── catalog/                 # Каталог плагинов и их скиллов
    │   ├── SKILL.md
    │   └── references/plugin-catalog.md
    ├── route-request/           # Маршрутизация задачи к скиллу
    │   ├── SKILL.md
    │   └── references/routing-matrix.md
    └── cross-functional-workflow/  # Сквозные межфункциональные процессы
        ├── SKILL.md
        └── references/workflows.md
```

## Скиллы

| Скилл | Что делает |
|---|---|
| `start` | Входная точка. Определяет домен задачи и сценарий: каталог, маршрутизация или сквозной процесс |
| `catalog` | Показывает все плагины и скиллы, помогает выбрать нужный |
| `route-request` | Находит правильный скилл под запрос по матрице маршрутизации |
| `cross-functional-workflow` | Ведёт сквозные процессы: запуск продукта, найм, закрытие месяца, онбординг клиента, операционное изменение |

## Установка

```bash
# В Claude Code, из корня репозитория-маркетплейса
claude plugin install orchestrator

# Или как отдельную папку
claude plugin install /path/to/orchestrator
```

В Cowork — импортируйте папку `orchestrator/` через интерфейс плагинов.

## Как использовать

Скиллы срабатывают автоматически по релевантности:

- «Помоги запустить наш новый продукт» → сквозной процесс GTM.
- «Подготовь меня к звонку с Acme» → маршрутизация на `sales/call-prep`.
- «Что ты умеешь?» → каталог плагинов.

## Кастомизация

- Плагины и скиллы в `references/plugin-catalog.md` соответствуют маркетплейсу knowledge-work-plugins. При появлении новых плагинов обновите каталог и матрицу маршрутизации.
- Добавляйте собственные сквозные процессы в `references/workflows.md` по схеме из конца файла.
- Для автора плагина укажите своё имя в `.claude-plugin/plugin.json`.
