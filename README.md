# Агентская система knowledge-work (opencode)

Агентская система для работы с плагинами [knowledge-work-plugins](https://github.com/SunnyS8/knowledge-work-plugins) в [opencode](https://opencode.ai). Работает на любой модели (проверено на DeepSeek): скиллы и агенты — это markdown-инструкции, а не привязка к конкретной LLM.

## Возможности

- **Оркестратор** (primary-агент по умолчанию) — определяет домен задачи и направляет её профильному специалисту или ведёт сквозной процесс.
- **14 специалистов** — субагенты по доменам: продажи, маркетинг, финансы, данные, право, поддержка, продукт, HR, инженерия, дизайн, операции, логистика, малый бизнес, корпоративный поиск.
- **155 скиллов** — портированные инструкции и workflow из маркетплейса.
- **Сквозные процессы** — запуск продукта, найм, закрытие месяца, онбординг клиента, внедрение изменений.
- **MCP-коннекторы** — справочник из 63 серверов маркетплейса; примеры в `opencode.json` (отключены до включения).

## Быстрый старт

```bash
# установить opencode (если ещё нет)
# перейти в проект и запустить
opencode
```

При старте работает агент `orchestrator`. Просто опиши задачу, например:

- «подготовь меня к звонку с Acme» — маршрутизация на `sales-specialist`;
- «запустим наш новый продукт» — сквозной GTM-процесс;
- «что ты умеешь?» — каталог скиллов и специалистов.

Или вызови специалиста напрямую: `@finance-specialist сверь банк за июнь`.

## Команды

| Команда | Действие |
|---|---|
| `/orchestrate <задача>` | Оркестрация задачи |
| `/catalog [домен]` | Каталог скиллов и специалистов |
| `/workflow <процесс>` | Сквозной рабочий процесс |

## Структура

```
├── opencode.json            # default_agent: orchestrator, MCP (disabled)
├── AGENTS.md                # правила и архитектура для агентов
├── scripts/sync-skills.ps1  # обновление скиллов из маркетплейса
├── .opencode/
│   ├── agents/              # orchestrator + 14 специалистов
│   ├── skills/              # 155 скиллов (оркестратор, connectors, sync, домены)
│   └── command/             # /orchestrate, /catalog, /workflow
└── orchestrator/            # исходная Cowork-версия оркестратора (необязательна)
```

## Безопасность

- Специалисты finance, legal, small-business запрашивают подтверждение перед изменениями файлов и запуском команд.
- Действия с деньгами, клиентами и юридическими обязательствами — только после явного подтверждения пользователя.

## Обновление скиллов

```powershell
powershell -ExecutionPolicy Bypass -File scripts/sync-skills.ps1
```

или попроси агента: «обнови скиллы из маркетплейса» (скилл `orchestrator-sync`). После обновления перезапусти opencode.

## Подключение внешних инструментов

Справочник всех коннекторов — в скилле `connectors` (`.opencode/skills/connectors/references/connectors.md`). Включение: добавь сервер в `mcp` в `opencode.json` (`enabled: true`) и перезапусти opencode. Без коннекторов все скиллы работают в автономном режиме по данным пользователя.
