# Каталог скиллов

Показывай пользователю доступные скиллы, помогай выбрать подходящий под задачу.

## Порядок работы

1. Открой файл `references/plugin-catalog.md` рядом с этим скиллом (инструмент Read) — там полный список скиллов по доменам.
2. Сопоставь запрос пользователя с подходящим скиллом по таблице "Что для чего".
3. Представь результат понятно: домен → скилл → для чего.
4. Если пользователь не знает, что выбрать, задай 2–3 уточняющих вопроса (роль, задача, используемые инструменты) и дай конкретную рекомендацию: какой скилл запустить первым.

## Правила

- Список скиллов бери только из каталога, не выдумывай.
- Запускай выбранный скилл через инструмент `skill`.
- Если задача межфункциональная, отметь это и предложи скилл `orchestrator-workflow`.
- Отвечай на русском языке.
