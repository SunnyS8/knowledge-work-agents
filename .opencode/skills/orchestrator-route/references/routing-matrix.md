# Матрица маршрутизации

Сопоставляет типовые запросы со скиллом. Если запрос пользователя покрывает несколько строк — это кандидат на сквозной процесс (`orchestrator-workflow`).

## Продажи и рост (sales)

| Запрос | Скилл |
|---|---|
| Подготовь меня к звонку / встрече с [компания] | sales: call-prep |
| Исследуй компанию / контакт перед первым контактом | sales: account-research |
| Напиши аутрич / email / LinkedIn-сообщение | sales: draft-outreach |
| Прогноз по воронке, квоте, сценарии | sales: forecast |
| Разбери воронку: здоровье, риски, приоритеты | sales: pipeline-review |
| Обработай заметки / транскрипт после звонка | sales: call-summary |
| Собери конкурентную разведку / battlecards | sales: competitive-intelligence |
| Сделай ассет для проспекта (лендинг, one-pager, дек) | sales: create-an-asset |
| Ежедневный бриф продавца | sales: daily-briefing |

## Особые случаи

- Задача затрагивает несколько доменов → `orchestrator-workflow`.
- Нужен просмотр/подпись PDF → pdf-viewer: view-pdf.
- Доклинические исследования, геномика, литература → bio-research.
- Создать новый скилл/плагин → cowork-plugin-management.
